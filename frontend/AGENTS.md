# Frontend Agent Instructions

## Project Guidelines

Este documento contiene las reglas e instrucciones generales para el desarrollo del frontend.

El objetivo es mantener una interfaz moderna, consistente y alineada con el diseño definido.

---

# UI Theme

La aplicación debe utilizar una estética **Dark Mode** con estilo tecnológico/médico.

La inspiración visual está basada en:
- Fondos oscuros
- Componentes con bordes suaves
- Inputs tipo glass/dark UI
- Acciones principales con color cyan
- Alto contraste y buena legibilidad

---

# Color Palette
Usar estas variables como referencia global:

--background-primary: #0A0A0A;
--background-secondary: #11252C;

--primary: #1B5060;
--accent: #00D9FF;

--text-primary: #FFFFFF;
--text-secondary: #A7B8BD;

--border-color: #1A3A43;

# Layout
Priorizar:
- Diseño responsive
- Mobile first
- Espaciados consistentes
- Componentes reutilizables
